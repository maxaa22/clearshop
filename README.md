# Чистий Шоп

Легкий Android-додаток на WebView у стилі Liquid Glass. Він відкриває справжній temu.com і має:

- скляну нижню панель із кнопками «Головна», «Пошук», «Кошик» і «Оновити»;
- блокування рекламних і трекінгових доменів;
- автоматичне приховування промо-вікон (купони, колесо удачі, «завантажте додаток»), при цьому вікна входу, оплати, вибору розміру й кошика не чіпаються;
- блокування переходів у Play Market і сторонні додатки;
- екран «Немає з'єднання».

## Як отримати APK (через GitHub, без комп'ютера)

1. Створи на GitHub новий репозиторій і завантаж туди вміст цієї папки (разом із `.github`).
2. Відкрий вкладку **Actions** і дочекайся, поки «Build APK» стане зеленим (≈3–4 хв).
3. Відкрий цей запуск, унизу в розділі **Artifacts** завантаж `ClearShop-apk`, розпакуй zip і встанови APK.

Посилання на сторінки та список заблокованих доменів лежать на початку `MainActivity.java`.
Правила для спливаючих вікон (слова PROMO / SAFE) — у `app/src/main/assets/clean.js`.
